# 重邮天协 · 雾都之上，我们收听星光

重庆邮电大学天文爱好者协会的静态网站。首页是一整片缓慢自转的银河；移动光标扫描旋臂，捕获那颗会闪的恒星——太阳系，点进去之后，可以框选任意一颗行星，滚轮推进，进到它的介绍页。

整个站点是零依赖的静态文件：没有构建步骤，没有后端，直接放到 GitHub Pages 上就能访问。

---

## 本地预览

```bash
# 任选一种
python -m http.server 4173        # 需要能跑 http 服务，不能直接双击 index.html
npx serve .
```

仓库里还带了一个不依赖任何包的预览器：

```bash
node tools/serve.mjs . 4173
# 打开 http://127.0.0.1:4173/
```

> 页面用的是 ES module + WebGL。`file://` 直接打开会因为模块的跨域限制而失败，必须走 http。

## 部署到 GitHub Pages

1. 新建仓库，把**除 `.dsh/`、`tools/`、`.shots/` 之外**的文件推到仓库根目录。
   `.gitignore` 已经把这几个目录排除掉了，直接 `git add .` 就行。
2. 仓库 Settings → Pages → **Source: Deploy from a branch**，分支选 `main`，目录选 `/ (root)`。
3. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`。

几点需要注意：

- 站点全部使用相对路径，放在子路径下（如 `/cqupt-astro/`）也能正常工作。
- 仓库里的 `.nojekyll` 是必须的，否则 GitHub 的 Jekyll 会忽略以下划线开头的文件。
- 路由用的是 `#/` 哈希，刷新任何一页都不会 404，不需要额外的 404 配置。
- 首页没有首屏大图，只有 WebGL 画布；如果希望社交平台分享时有缩略图，可以在 `index.html` 里补 `<meta property="og:image">`。

## 目录

```
index.html            页面骨架与协会页正文
css/site.css          全部样式（顶部是设计 token，改颜色从这里改）
js/app.js             路由、场景切换、协会页的「今晚的天」
js/galaxy.js          银河（二十万个粒子 + 尘埃带 + 太阳系信标）
js/system.js          太阳系（轨道、行星、卫星、小行星带、框选与推进）
js/planet.js          单颗天体的自转球体
js/bodies.js          11 个天体的全部文案与数据
js/ephemeris.js       JPL 近似轨道根数 + 月相，用来算「今晚的天」
assets/textures/      行星表面贴图
assets/photos/        协会页照片（含 credits.json）
assets/vendor/        three.js r169
```

## 改内容

**天体数据与文案**：`js/bodies.js`。每个天体一个对象，`figures` 是详情页的数据表，`body` 是正文段落，`observe` 是观测建议。改文字只需要动这个文件，页面会自动更新。

**协会页**：正文在 `index.html` 的 `<section class="view view--society">` 里，是普通的 HTML。

**颜色与字号**：`css/site.css` 顶部的 `:root`。全站只用这几个 token，改一处就能整体换色。

**「今晚的天」**：不用改。打开页面时由 `js/ephemeris.js` 现算，包括月相、天文昏影起止、每颗行星今夜的可见时段与最高地平高度。

## 交互

| 操作 | 效果 |
| --- | --- |
| 移动光标（银河页） | 扫描旋臂；靠近太阳系时信号强度上升，读数变暖色 |
| 点击信标 / 「直接进入太阳系」 | 以这颗光点为锚放大到画面正中，再拉开；21 万粒子重组成轨道与行星，行星直接在光斑里长出来（约 3.2 秒） |
| 点击行星 / 标签 | 框选，右侧出现信息卡 |
| 滚轮（已框选时） | 推进，满格后进入介绍页 |
| 滚轮（未框选时，太阳系页） | 拉近 / 拉远整个太阳系 |
| 拖动 | 旋转视角 |
| 「重置视角」 | 回到初始机位并取消框选 |
| 「加入」 | 从协会页顶部先快后慢滚到加入板块 |
| `Esc` | 取消框选 |
| `←` `→`（行星页） | 上一颗 / 下一颗 |

手机上没有滚轮：点行星框选后，直接点信息卡进入。协会页与天体页的整屏背景是失焦的太阳系，滚轮照常滚动页面。

## 浏览器要求

需要支持 WebGL 与 ES module 的现代浏览器（Chrome / Edge / Safari 16+ / Firefox 近期版本）。开了「减少动态效果」的系统设置时，银河与行星的转动会自动停下，内容不受影响。
